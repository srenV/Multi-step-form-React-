# Multi-Step Form (React)

A multi-step form web app built with React and Vite. This project is one of my early React projects — I'm still learning, and the app needs further work and polish.

Live site : [<a></a>](https://multi-step-form-theta-brown.vercel.app/)

## Features

- Multi-step form with validation
- Step navigation (previous/next)
- Form context for state management
- Progress tracking with sidebar
- Responsive design with Tailwind CSS

## Getting Started

Prerequisites:

- Node.js (>=16)

Install and run:

```bash
npm install
npm run dev
```

Open http://localhost:5173 (Vite default) in your browser.

## Project Structure

- `src/` — source files (components, context)
- `src/components/` — form steps (FirstForm, SecondForm, ThirdForm, FourthForm) and sidebar
- `src/context/` — FormContext for state management
